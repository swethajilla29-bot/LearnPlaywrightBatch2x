## Tips for Mac Users

- **Customize Shortcuts**: Go to `Code → Preferences → Keyboard Shortcuts` or press `Cmd + K Cmd + S`
- **Search Shortcuts**: In Keyboard Shortcuts panel, use the search box to find specific commands
- **Keybinds JSON**: Click the "Open Keyboard Shortcuts (JSON)" icon to edit `keybindings.json` directly
- **Conflict Resolution**: VS Code will warn you about conflicting shortcuts
- **Cmd vs Ctrl**: On Mac, most shortcuts use `Cmd` (Command key) instead of `Ctrl`
- **Opt vs Alt**: The `Alt` key on Mac is the `Opt` (Option) key

## Common Mac Differences from Windows/Linux

| Windows/Linux | Mac | Action |
|---------------|-----|--------|
| `Ctrl` | `Cmd` | Most primary shortcuts |
| `Alt` | `Opt` | Modifier key |
| `Ctrl + Z` | `Cmd + Z` | Undo |
| `Ctrl + Shift + Z` | `Cmd + Shift + Z` | Redo |
| `Ctrl + X` | `Cmd + X` | Cut |
| `Ctrl + C` | `Cmd + C` | Copy |
| `Ctrl + V` | `Cmd + V` | Paste |
| `Ctrl + A` | `Cmd + A` | Select All |
