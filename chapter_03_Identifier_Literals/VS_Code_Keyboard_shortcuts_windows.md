## Tips for Windows Users

- **Customize Shortcuts**: Go to `File → Preferences → Keyboard Shortcuts` or press `Ctrl + K Ctrl + S`
- **Search Shortcuts**: In Keyboard Shortcuts panel, use the search box to find specific commands
- **Keybinds JSON**: Click the "Open Keyboard Shortcuts (JSON)" icon to edit `keybindings.json` directly
- **Conflict Resolution**: VS Code will warn you about conflicting shortcuts
